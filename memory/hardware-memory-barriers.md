- 内存保序问题中，锁通常会同时涉及硬件屏障和软件屏障。软件屏障是编译器层面的优化，用于阻止编译器对内存访问指令进行重排；而硬件屏障则是CPU层面的指令，确保CPU执行内存操作的顺序。在实现锁时，进入临界区前可能需要插入读屏障和写屏障，防止临界区内的内存操作被重排到外面，退出时也需要类似屏障来保证其他线程能看到最新的内存状态。具体使用哪种屏障取决于CPU架构和编译器，但锁的实现通常会组合两者来确保内存顺序的正确性。
